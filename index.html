Highcharts Optimization Engine

I designed and built this product from scratch. Its aggregation pipeline takes deeply nested, unfiltered API data and turns it into chart-ready series, using a flattening algorithm that mixes DFS with cross-multiplication. I also wrote a prompt template to improve developer experience and let the engine plug in as an MCP tool.
